# Joke Taiwo Ogundairo — Lead DevOps Engineer Landing Page

A focused biography landing page positioning Joke Taiwo Ogundairo for senior DevOps, cloud infrastructure, platform engineering, AI infrastructure, automation and engineering leadership opportunities.

## Built with

- Vite
- React
- CSS
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Netlify

This repo includes `netlify.toml`. Netlify build settings:

- Build command: `npm run build`
- Publish directory: `dist`

## Notes

The page copy is based on the attached DevOps resume/biography and is intentionally written for companies evaluating engineering leadership, not as a first-person personal bio.
